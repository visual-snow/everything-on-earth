# RxCare Capabilities

RxCare is a JavaScript-based pharmacy management platform for retail pharmacy store owners. It provides patient management, inventory tracking, a scheduling calendar, and an AI-powered virtual pharmacist assistant. The project is a work-in-progress; role-based access control, API security, and logging are not yet implemented.

## Patient Management

- Patient records with a 360-degree detail view linking to a drug compound database
- Patient search and browse across single-store or multi-store deployments

## Inventory and Operations

- Inventory tracking for pharmacy stock
- Calendar for pharmacist managers and workers to coordinate schedules
- Dashboard for operational overview
- FAQ module for staff reference

## AI Assistant

- A virtual pharmacist assistant provides AI-powered guidance within the platform

## Deployment Modes

- Single-store mode for independent pharmacies
- Multi-store mode for pharmacy chain operations

## Constraints

- Role-based access control is not yet implemented; all users share the same access level
- API security is explicitly listed as incomplete and pending development
- User model persistence to database is an open to-do item
- No documentation or live demo is published
- No test suite, deployment configuration, or CI/CD pipeline
- No HL7, FHIR, or other healthcare interoperability standards
