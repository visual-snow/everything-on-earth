Hospital Training Portal

Open-source medical staff training tools for trauma and mass casualty triage. All modules run locally; no internet required after setup.

Offline-capable
Training Modules
🔴

START Triage Trainer

Interactive mass casualty triage training. Practice the START algorithm with randomized virtual casualties. Score your accuracy and speed. Mass casualty drill mode with 20 patients.
For: All medical staff, first responders, volunteers
Skills: Triage decision-making, rapid assessment, prioritization under pressure
Ready (no setup needed)
🏥

Hospital Simulation

AI-powered simulated hospital environment. Interact with virtual patients presenting trauma symptoms. Make diagnostic and treatment decisions. Powered by MedAgentSim + local LLM.
For: Physicians, medical residents, advanced nurses
Skills: Differential diagnosis, trauma assessment, clinical reasoning
Requires Ollama (LLM)
🦴

3D Anatomy Atlas

Interactive 3D anatomy viewer. Explore human anatomy in the browser with labeled structures. Understand injury sites, surgical anatomy, and anatomical relationships.
For: All clinical staff, medical students
Skills: Anatomical knowledge, surgical planning reference
Ready (no setup needed)
📋

START Algorithm Reference

Quick reference for the START (Simple Triage and Rapid Treatment) algorithm. Flowchart view with decision points and color-coded categories. Built into the triage trainer; click "Show START Algorithm Reference."
For: Quick reference during training or field use
Skills: Protocol recall, triage procedure
Ready (no setup needed)

Deployment

This training portal runs entirely on Docker. To start all modules:

./start.sh

On first run, the startup script downloads the Ollama LLM model (~4GB). After that, everything works offline. The triage trainer and anatomy modules work immediately with no LLM dependency.

Minimum hardware: any laptop with 8GB RAM and Docker installed. Recommended: 16GB RAM for running the LLM-powered hospital simulation.
